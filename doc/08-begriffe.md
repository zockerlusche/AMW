# 08 · Begriffe

| Begriff | Bedeutung |
|---|---|
| AMW | Agentenmanagement Workbench – dieses Projekt |
| Entwickler | Marcel; entscheidet, steht über dem Team |
| TL | Tech-Lead-Agent; führt die Agenten, spricht mit dem Entwickler |
| Agent | Claude-Code-Sitzung mit fester Rolle (CC1 …, CCamw) |
| Bus | die gemeinsame Datenbank, über die TL und Agenten kommunizieren |
| Wache | kleiner Hintergrund-Prozess je Agent, der ihn bei neuer Arbeit weckt |
| Puls | Lebenszeichen eines Agenten (letzte Meldung) |
| Rechen-Job / Lauf | speicher- oder schirmlastige Arbeit (Build, Test, Messung); angemeldet, einer zur Zeit |
| Schirm | Marcels Bildschirm für Abnahmen; frei nur ohne Fernwartung |
| Beschluss | eine Festlegung mit Quelle; kann von einem späteren ersetzt werden |
| Arbeitsregel | wie Agenten arbeiten (heute Tabelle kernregel) |
| Projektregel | was im Projekt gilt (LayerIT: Tabelle baugesetz) |
| Wortlaut | jede Aussage des Entwicklers, unverändert gespeichert |
| Frage | Frage an den Entwickler mit Optionen, Empfehlung, Grund, Vorgeschichte |
| Rückfrage | Antwort des Entwicklers, die eine Erklärung verlangt |
| Bogen | zusammenhängender Arbeitsabschnitt (mehrere Aufgaben) |
| Entwurf | Änderung, die erst nach Freigabe in die echten Daten geht |
| Lokal zuerst | jeder Rechner arbeitet gegen seine eigene Datenbank, ein Dienst gleicht mit dem zentralen Speicher ab |
| Veröffentlichter Auszug | freigegebene Release Notes/Blog-Einträge, die die Homepage liest |
| Komprimieren | ein Agent fasst seinen Verlauf zusammen und verliert dabei Einzelheiten |
