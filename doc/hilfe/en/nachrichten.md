# Messages: inbox and sent

Everything you write to agents and everything they write to you is in one place. For each recipient you see how far a message has got – and as long as nobody has read it, you can withdraw it.

## You need
- The Workbench at the PC or the online site. Menu › Messages.

## Steps
1. **Write** Messages › “+ Write” – pick a recipient (one agent or everyone), type, text. From an agent (“Message”) the recipient is already filled in.
2. **Follow the status** “Sent” tab: per recipient sent › notified › read › done. Hover over a step to see the time.
3. **Read replies** Clicking a message shows the conversation on the right – your message and what came back. On a phone it opens as its own view (“‹ Back to list” returns).
4. **Work through the inbox** “Inbox” tab: unread is bold. “Reply” writes back, the reference (e.g. the task) comes along; “Done” removes it from the count in the menu.

## What the steps mean
- **sent** – the message is in AMW.
- **notified** – the service has woken the agent. Chat leads read on their next round.
- **read** – the agent has fetched it with `amw lesen`.
- **done** – the agent has dealt with it.
- **being sent …** – online only, until the PC has taken it over.

## Withdraw
Sent › pick a message › “Withdraw”. This works as long as **no** recipient has read or done it; it then disappears for every recipient and stays with you as “withdrawn”. If someone has already read it, the button is greyed out – send a new message instead (“please ignore”).

## Common mistakes
- **A message stays at “sent” for a long time** – The agent is not running, or it is a chat lead that only reads on its own rhythm. The start page shows whether it is running.
- **The reference is missing** – Only messages about a task, a document or a question have one; new messages from the menu are general.

## Afterwards
- You keep answering the agents' questions under “Questions” (the tab there takes you to it).
